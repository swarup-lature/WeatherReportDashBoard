# Weather Report Dashboard

A comprehensive weather monitoring and reporting dashboard built using Power BI and connected to a live Weather API[cite: 3].

## 📊 Project Overview
The Weather Report Dashboard is designed to track, analyze, and visualize critical meteorological metrics across multiple cities. It processes live data streams to deliver actionable insights regarding temperature fluctuations, humidity levels, and air quality indices[cite: 3].

## 🛠️ Tech Stack & Tools
* **Power BI**: Primary data visualization and dashboard development platform[cite: 3].
* **DAX (Data Analysis Expressions)**: Used for building custom calculated measures to analyze weather trends[cite: 3].
* **Live Weather API**: External data source supplying real-time weather and air quality metrics[cite: 3].

## 📈 Key Features & Capabilities
* **Multi-City Analysis**: Monitors temperature, humidity, and air quality metrics across four major urban locations[cite: 3].
* **Interactive Visuals**: Implements dynamic charts and dashboards to represent weather conditions clearly.
* **Real-time Data Integration**: Connects directly to a live API endpoint to ensure up-to-date reporting[cite: 3].
